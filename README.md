# Potemkin Findings: Calibrating AI Research Loops with Null Worlds

This is the research artifact for a submission to the *Organization Science* special issue **AI-Enabled Frontiers in
Organizational Science** (Stage 1 deadline 1 November 2026).

Once an AI agent can run a whole empirical research loop, how often does it report findings that are not there? And how
can its search be priced? The answer here is **Null-World Calibration (NWC)**. The loop is replayed on counterfactual
versions of the real data in which the hypothesized effects are absent by construction.

## Main results (all numbers regenerated by the scripts; see `manuscript/numbers.tex` and `manuscript/numbers_validity.tex`)

**Testbed.** 34,333 firm-years at 4,078 listed firms (2016–2025). The shock is ChatGPT (30 Nov 2022); treatment intensity
is predetermined (2019–2021) LLM exposure.
- H1: a 1-SD higher exposure raises the experienced-hire share by 1.21 pp (t = 9.7).
- Adoption first stage: F = 562.
- Pre-trends: the joint pre-trend test rejects (p = 0.011), from a 2017–2018 drift that runs *against* H1.
  The trend-adjusted estimate is larger (1.38 pp), and the estimate holds even if post-2022 trend differences were 1.5
  times the largest seen before (Rambachan–Roth breakdown value).
- Measurement audit: the skill label "GitHub Copilot" is correct for only 2.6% of rows, and a skill's "first reported"
  date tracks when the résumé was collected, not when the skill was adopted.

**The unguarded loop.** Rule U (registered moderator signs) reports a fully significant H1–H4 package after 3,483 models;
rule U-free (signs rationalized after the fact) after 12. Search-adjusted p-values replay the loop in 1,000 Type A null
worlds (H1, package) and 500 Type B worlds per moderator:

| Hypothesis | Nominal t | Search-adjusted p | Holm over all ten candidate moderators |
|---|---|---|---|
| H1 (exposure cuts entry-level hiring) | -10.6 | ≤ 0.001 | |
| H2 hierarchy shape amplifies | -5.6 | 0.002 | 0.020 |
| H3 digitizable work amplifies | -4.6 | 0.046 | 0.413 |
| H4 organizational age attenuates | 2.6 | 0.313 | 1.000 |
| The package as a whole | | 0.056 | |

- H1's best t during the search (12.1) beats all 1,000 null worlds.
- Only hierarchy shape survives the correction for the ten registered candidates. Holm over the three reported
  moderators alone would confirm one in 14.4% of worlds in which none of the ten matters (Holm over ten: 4.7%).
- Hierarchy shape also survives conditional shuffles and rebuilt-outcome (Freedman–Lane) worlds (Holm over ten: 0.020 in
  each), and its best screening t, defined in every world, is never beaten in its shuffled worlds (p ≤ 0.002).
- Correcting for every model the registry allows is valid but blunter: package p = 0.124, against 0.056 when the loop's
  actual stopping rule is replayed.
- Split-sample guard: no full package in the search half; H1 holds in the confirmation half (t = 7.4), but only one of
  its three moderators does.

**Potemkin rates** (share of 1,000 Type A null worlds reporting a full package):

| Procedure | Rate |
|---|---|
| Unguarded loop U | 26.5% |
| Sign-rationalizing loop U-free | 93.4% |
| Bonferroni over models visited | 0.0% |
| Specification curve (median t ≥ 1.96) | 3.3% |
| NWC (loop-level p ≤ 0.05) | 5.0% |
| Split-sample guard | 0.6% |

- Risk grows with the search budget: U reports a full package within 1,000 models in 3.7% of null worlds and within the
  3,483 it used on the real data in 25.7%; U-free does so within 12 models in 8.3%.
- With all ten moderators shuffled at once (joint worlds), U still reports a full package in 94.0% of worlds.

**Validity diagnostics** (added after the main results were seen; `scripts/22`–`28`):
- Exposure is not exchangeable within sector (correlation 0.62 with digitizable work). On synthetic twins, a trait that
  shifts outcomes only in levels is harmless (6.0% false alarms at the 5% level). A trait that shifts them after 2022 is
  a confounder: false alarms reach 43% when its spurious effect is 9% of the H1 estimate. Worlds that keep exposure's link
  to the trait restore the correct rate (at most 7.5% across 12 settings).
- On the real data, worlds that keep exposure's link to twelve predetermined traits give p ≤ 0.001 for H1 and p = 0.137
  for the package; U's Potemkin rate rises to 40.3%.
- Moderators with no true interaction: a correlated moderator with a real effect plus a curved exposure effect push the
  simple shuffle to 95% false alarms. The conditional shuffle keeps 4.5%; rebuilt-outcome worlds are cautious (0.5%).

**Monte Carlo** (synthetic twins with known truth; NWC test of the searched main effect):

| Scenario | Rejection rate |
|---|---|
| Null | 5.0% |
| Design space pruned after peeking, not replayed | 10.3% |
| Pruning replayed | 5.0% |
| Confounded | 90% |
| Planted effects (power) | 100% (package test: 82%) |

## The package (`nullworld/`)
- `fe.py` provides multi-way fixed-effects demeaning (alternating projections) and cluster-robust OLS. It is validated
  against `pyfixest` to 1e-15 (`scripts/90`, `scripts/91`). One full replay of the loop (both policies, about 5,647
  fits) takes 2.5 seconds, 72 times faster than refitting with `pyfixest` (`scripts/27`).
- `loop.py` holds the registry-driven, replayable research loop:
  - policy **U** respects the registered moderator signs;
  - policy **Ufree** lets the loop rationalize signs after the fact;
  - `run_both` evaluates both policies in one pass.
- `worlds.py` generates the worlds:
  - **Type A** permutes the treatment within strata;
  - **Type B** permutes one moderator within sector × treatment-quintile strata;
  - **planted worlds** add known effects.
- `infer.py` computes loop-level randomization p-values, the Holm adjustment, and Monte Carlo bands.
- `synth.py` fits the synthetic twin (Gaussian copula plus AR(1) panel) and generates from it.
- `registry.py` verifies the registry hash and turns the registry into a loop grammar.

## Data
Revelio Labs (positions, skills, postings, company mapping), Compustat North America, and I/B/E/S are licensed and cannot
be redistributed. The scripts document every field used, and licensees can regenerate every number. The public exposure
scores are in `data/external/`, each with its source URL.

**Running without licensed data.** Set `NULLWORLD_DATA=synthetic` and the loop and all null worlds (`scripts/10`–`11`)
run on the synthetic twin in `synthetic/`. The Monte Carlo studies (`scripts/13`, `23`, `24`) simulate their own twins,
and the figure and table scripts read the stored outputs in `intermediate/`. Scripts 01–09, 12, 14, 22, 25, and 27 read
the licensed data directly.

The licensed extracts (`data/analysis/`, `data/raw_extracts/`) are not in this repository. The registry's `authoring`
field refers to the agent's instruction file `research_skills.md`, which is not included.
